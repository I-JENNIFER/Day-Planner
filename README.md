# 🌅 DayFlow — Smart Daily Planner

A modern, minimal daily planner that helps you build consistent routines and track your productivity over time.

🔗 **Live Demo → [day-planner-olive.vercel.app](https://day-planner-olive.vercel.app)**

---

## ✨ Features

- **Smart Dashboard** — See your current activity, what's coming up next, and daily progress at a glance
- **Customizable Routines** — Separate schedules for Office days, Remote days, and Weekends
- **Activity Categories** — Color-coded categories: Exercise, Study, Work, Chores, Entertainment, Sleep, Commute
- **Progress Tracking** — Check off activities and watch your daily completion percentage grow
- **Weekly Analytics** — Bar chart showing your completion rate over the past 7 days
- **Calendar Export** — Export your daily schedule as a `.ics` file to Google Calendar, Apple Calendar, or Outlook
- **Local Persistence** — Your schedule and progress are saved locally across sessions
- **Responsive Design** — Works great on both desktop and mobile

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/I-JENNIFER/Day-Planner.git

# Navigate into the project
cd Day-Planner

# Install dependencies
npm install

# Start the dev server
npm run dev
```

---

## 💡 Why I Built This

I wanted a simple, distraction-free way to plan my day without the complexity of most productivity apps. DayFlow is built around the idea that a consistent routine — not just a to-do list — is what drives real progress.

---

## 📈 What I Learned

- Building reusable React components with TypeScript
- Managing state and local persistence with localStorage
