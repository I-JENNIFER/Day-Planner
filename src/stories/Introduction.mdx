# DayFlow Component Library

Welcome to the DayFlow Storybook! This is an interactive documentation of all the UI components used in the DayFlow daily planner app.

## Components

### UI Primitives
- **Button** — Action buttons in various styles (default, outline, ghost, destructive)
- **Badge** — Category labels, day selectors, and status indicators
- **Card** — Activity cards, stat cards, and the current activity display

### App-Specific Patterns
Each story showcases how the base shadcn/ui components are composed into DayFlow-specific patterns:
- **Activity Cards** — Normal and completed states with category badges
- **Current Activity Card** — The dark hero card showing current activity and progress
- **Stat Cards** — Analytics summary cards (7-day average, today, best day)
- **Category Badges** — Color-coded badges for all 8 activity categories
- **Day Badges** — Selectable day-of-week badges for the planner

## Tech Stack
- **React 19** with TypeScript
- **shadcn/ui** components (built on Base UI + CVA)
- **Tailwind CSS 4** for styling
- **Lucide React** for icons
